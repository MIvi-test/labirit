# Labirit

Генератор лабиринтов на C для Linux. Поддерживает алгоритмы Прима, DFS, растущего дерева, Уотсона, двоичного дерева и рекурсивного разделения.

Нужны GNU Make и компилятор C с поддержкой C23.

## Запуск

```bash
make
```

Команда собирает программу и выводит лабиринт 10×10. Чтобы выбрать алгоритм, размер и seed, сначала соберите программу, затем запустите её с аргументами:

```bash
make compile
./main dfs 20 12 42
```

Формат: `./main [алгоритм] [столбцы] [строки] [seed]`. Если seed не задан, он выбирается случайно. Для списка аргументов используйте `./main --help`.

## Другие команды

```bash
make benchmark  # запустить бенчмарки; JSON-файлы результатов перезаписываются
make test       # собрать и запустить тесты
make clean      # удалить собранные программы
```


# Уникальная информация

В этой ветке идёт оптимизация алгоритма генерации. Сама оптимизация является компромисом, так как увеличение в скорости и улучшение ассимтотической нотации big O было совершено засчёт увеличение в 1.5-2 раза памяти (доп 8 байт на клетку).

## Суть проблемы

В исходной реализации активные клетки хранились в плотном массиве `active`, а время их добавления в `active_age`.

В 60% итераций генератор перебирал активный массив, чтобы найти клетку с максимальным возрастом. Стоимость одного такого выбора составляла O(M), где M — текущее число активных клеток.

## Детали реализации 

Вместо active_age используются:

| Структура | Назначение |
|---|---|
| active[position] | Плотный массив для случайного выбора |
| position[cell] | Позиция клетки в active |
| older[cell] | Предыдущая активная клетка по порядку добавления |
| newer[cell] | Следующая активная клетка по порядку добавления |
| newest | Последняя добавленная активная клетка |

При добавлении клетка дописывается в `active` и становится концом списка. При удалении клетка исключается из списка, а в плотном массиве заменяется последним элементом с обновлением его позиции.

Выбор newest, случайный выбор, добавление и удаление выполняются за O(1)
