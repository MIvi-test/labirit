# Labirit

Генератор лабиринтов на C для Linux. Поддерживает алгоритмы Прима, DFS, растущего дерева, Уотсона, двоичного дерева и рекурсивного разделения.

Нужны GNU Make и компилятор C с поддержкой C23.

## Запуск

```bash
make
```

Команда собирает программу и выводит лабиринт 10×10. Чтобы выбрать алгоритм, размер и seed, сначала соберите программу, затем запустите её с аргументами:

```bash
make compile
./main dfs 20 12 42
```

Формат: `./main [алгоритм] [столбцы] [строки] [seed]`. Если seed не задан, он выбирается случайно. Для списка аргументов используйте `./main --help`.

## Другие команды

```bash
make benchmark  # запустить бенчмарки; JSON-файлы результатов перезаписываются
make test       # собрать и запустить тесты
make clean      # удалить собранные программы
```



# УНИКАЛЬНАЯ ИНФОРМАЦИЯ О ВЕТКЕ

## Суть проблемы

В генераторах мы считаем шаги через labirit_metrics_step(1). Это полезно для сравнения алгоритмов, но само измерение тоже требует работы. Внутри каждого такого вызова раньше проверялось положительное значение аргумента и обновлялся общий счётчик. У Прима и Уотсона таких событий бывает особенно много: они появляются даже внутри проходов по вспомогательным структурам.


## Суть оптимизации

Идея простая: считать события рядом с вычислением, в локальной переменной, а общий итог обновлять после завершения функции. Смысл шага не меняется.

Это не даст большого ускорения всего бенча никак. Основную работу там выполняют обходы для расстояний, а задача 2 затрагивает генерацию и подготовку таблицы. Минорное, но явное ускорение кода

## Статистика

Как было протестировано локально, вне полного бенча, ускорение отличается, в зависимости от флага комплиляции. При -О2 полученный результат оптимизации становится ничтожным. Данные представлены ниже

| Prim | 127,661 | 131,653 | 112,825 | 117,630 |
| Growing tree | 8,094 | 4,393 | 2,829 | 2,826 |
| Watson | 29,744 | 23,824 | 4,172 | 4,167 |
| DFS | 0,204 | 0,160 | 0,117 | 0,110 |
| Binary tree | 0,047 | 0,042 | 0,036 | 0,034 |
| Recursive division | 0,111 | 0,085 | 0,054 | 0,056 |
