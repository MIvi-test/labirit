# Labirit

Генератор лабиринтов на C для Linux. Поддерживает алгоритмы Прима, DFS, растущего дерева, Уотсона, двоичного дерева и рекурсивного разделения.

Нужны GNU Make и компилятор C с поддержкой C23.

## Запуск

```bash
make
```

Команда собирает программу и выводит лабиринт 10×10. Чтобы выбрать алгоритм, размер и seed, сначала соберите программу, затем запустите её с аргументами:

```bash
make compile
./main dfs 20 12 42
```

Формат: `./main [алгоритм] [столбцы] [строки] [seed]`. Если seed не задан, он выбирается случайно. Для списка аргументов используйте `./main --help`.

## Другие команды

```bash
make benchmark  # запустить бенчмарки; JSON-файлы результатов перезаписываются
make clean      # удалить собранные программы
```


# Уникальная информация

На этапе анализа алгоритма бинарного дерева стало очевидно, что работа идёт последовательна по клеткам и независимо от предущих. Именно в таком типе работы удобно использовать SIMD.

## Детали реализации

Каждая клетка есть 1 байт, но она хранит информацию сразу по 4 стенам, а алгоритм затрагивает прежде всего только две стены, вверхнюю и нижнюю. Поэтому нельзя напрямую делать операцию И над rand() значением и лабиринтом, поэтому были реализованы маски(функция `expand_bits()`). 
Так как информация об одной и той же стене хранится сразу в двух клетках, то было сделано копирование результата с помощью: если на одной строке то битовый сдвиг + логическое И, если вертикаль, то битовое решение `нижняя_клетка &= ~(решение_вниз & бит_верхней_стены)`
